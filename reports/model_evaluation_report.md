# Model evaluation report

Generated by `train_models.py`; all numbers are computed from the data, nothing is hand-entered.

## Setup

- Data: `data/processed/ann_ready_dataset.csv` (642 rows, 34 districts). Target: `yield_t_ha`. Features: district (one-hot), year, area_ha, rain_kharif_mm, temp_kharif_c, rh_kharif_pct. Production is not used.
- Chronological split: train 1997-2015 = **540** rows; validation 2016-2017 = **51** rows; test 2018-2019 = **51** rows. No random splitting.
- Districts in validation/test but not in training: none. Baseline fallback for an unseen district = overall training mean (1.211 t/ha).
- StandardScaler (numeric) and OneHotEncoder (district) are fit on training rows only inside the pipeline.
- ANN: Input -> Dense(64, relu) -> Dense(32, relu) -> Dense(1, linear); Adam(1e-3), MSE, batch 32, EarlyStopping(val_loss, patience 30), up to 500 epochs. Trained with seeds [0, 1, 2, 3, 4]; the saved model/plots use the seed with the lowest validation loss (selected seed 0 for the full model, 2 for no-weather). The test set was never used to choose anything.
- Extra comparison (not requested): Linear Regression without weather, to judge weather fairly.

## Limitations

- Only 642 observations (540 train, 51 validation, 51 test); test metrics rest on two years.
- Four pairs of districts share a NASA grid cell (identical weather): Hingoli/Parbhani, Akola/Amravati, Nagpur/Wardha, Bhandara/Gondia.
- District weather is a single representative point (centre of the district boundary), not a district average.
- Historical correlations do not establish causation.
- Weather features are June-September totals/means, so they are only known after the growing season; this is retrospective estimation, not an early forecast.
- `year` is a feature and validation/test years lie beyond the training range; the models extrapolate any trend poorly.
- 17 validation/test rows come from areas under 1,000 ha, where yield is coarsely rounded.
- Academic prototype, not a production agricultural forecasting system.
